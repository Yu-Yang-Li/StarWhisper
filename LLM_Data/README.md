# LLM_Data

StarWhisper 3 的中英文训练问答数据。权重不在这里，在魔搭 [AstroYuYang/StarWhisper3](https://www.modelscope.cn/models/AstroYuYang/StarWhisper3)。

| 文件 | 内容 |
| --- | --- |
| `astro_cn_1.json` … `astro_cn_6.json` | 中文天文问答 |
| `Astro_en.json` | 英文天文问答 |
| `Physic.json` | 物理问答 |

这是清洗后的文本数据，不是观测原始数据，也不是 Telescope / Explore 的运行日志。4.0 仍在整理，权重还没放到这个目录。
