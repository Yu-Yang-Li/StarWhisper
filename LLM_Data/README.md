# LLM_Data

本目录保存 StarWhisper 3 的中英文训练问答数据。模型权重见魔搭 [AstroYuYang/StarWhisper3](https://www.modelscope.cn/models/AstroYuYang/StarWhisper3)。

[项目首页](../README.md) · [研究文档](../docs/research.md)

| 文件 | 内容 |
| --- | --- |
| `astro_cn_1.json` … `astro_cn_6.json` | 中文天文问答 |
| `Astro_en.json` | 英文天文问答 |
| `Physic.json` | 物理问答 |

这些文件为清洗后的问答文本，用于语言模型训练。观测数据和 Telescope / Explore 的实验材料见相应项目目录。StarWhisper 4.0 的资料仍在整理，本目录尚未提供其权重。
