# 论文引用检查

检查正文引用能否对应参考文献，以及引用是否支持所在句子的论述。正常流程用本地脚本提取证据，由当前模型审查，无需另申请模型 API 密钥。

## 怎么开始

确认论文文件与检查范围。天文论文编号、来源和引用习惯见 [astronomy.md](astronomy.md)。以下命令在本技能目录中运行：

```bash
python scripts/check_papercheck_env.py
python scripts/progressive_papercheck.py "paper.docx" --mode subjective --out "evidence.json" --report "report.md"
```

文件名换成实际路径；进度脚本也接受 PDF，并记录所用解析方法和缺失的依赖。单独的 `extract_citation_evidence.py` 用于 DOCX 提取。

## 选择检查深度

| 模式 | 检查什么 |
| --- | --- |
| `quick` | 结构提取和附带的 UCAS / GB/T 规则，不做语义审查 |
| `subjective` | 默认；规则检查，并准备当前模型的引用支持审查 |
| `full` | 增加对已提供原文、DOI 或开放来源证据的核验，并说明来源限制 |

附带规则不自动代表 AAS、MNRAS 或所有天文期刊的格式要求。规则输出、证据提取和模型判断要分别说明。需要配置、规则服务或 PDF 解析方法时阅读 [运行说明](references/runtime.md)。

## 逐条核对

1. 先查引用编号与参考文献是否对应，报告缺失和未使用条目。
2. 阅读引文所在句子、参考文献条目，以及已有原文证据。
3. 将结论写为支持、部分支持、支持较弱或待人工确认，并给出依据。
4. 范围引用如 `[1–3]` 要逐篇判断，不能让一篇论文代替其余条目。

只看到题名和引用上下文时，可以判断主题是否相关，不能声称已核对论文全文或证实结论。无匹配条目时先报告结构问题，不直接写成“该文献不支持论述”。

## 结果与记录

报告实际命令、输入与输出路径、检查方式、重点问题和证据限制。密钥、私人配置、上传论文、生成报告、依赖目录与缓存不打入技能包。缺少依赖时说明还能检查什么、哪些步骤没有执行。
