# 天文文献调研

围绕一个明确问题比较已有研究，整理引用、主要结论、分歧和仍需核验的部分。候选论文的查找与题名核对先用 [文献检索技能](../giiisp-paper-search-apis/SKILL.md)。

## 怎么开始

需要研究问题、已有候选论文、纳入范围和报告用途。先筛掉不相关的文献，再按 [astronomy.md](astronomy.md) 约定区分真实观测、仿真与决策日志。

1. 将宽泛问题拆成几项可以由文献回答的问题。
2. 记录检索词、来源、候选论文与排除理由。
3. 分别摘录方法、数据范围、结果和限制，保留论文编号与页码。
4. 比较支持和反对的证据，不把摘要中的陈述当成已读全文。
5. 写报告，并列出尚未核验的引用与结论。

## 使用远端服务时

只有选择远端 Deep Research 流程时，才阅读 [服务调用与日志](references/service-workflow.md)。其中保留请求字段、SSE 事件、历史实测记录和失败处理；历史记录不表示服务现在可用。脚本默认地址与 `--endpoint-url` 参数以实际脚本为准。

已有 SSE 日志可在本技能目录中回放，不调用服务：

```bash
python scripts/stream_deep_research.py --from-log ./events.sse
```

`events.sse` 换成实际日志。解析器示例与状态定义见上述参考文件。远端流程持续记录阶段和收到的内容；断流时保留引用、片段和最后事件，不把未完成回答标为完整报告。

## 报告需要包含什么

研究问题与范围、实际检索词与来源、主要结论及其引用、方法比较、争议或不足、可检验的下一步，以及需要全文核对的部分。

引用不足时标为初稿；只返回澄清问题时继续澄清。没有 `done` 的回答按实际状态记录为不完整。报告中保留 `evidence_used`、`claims_need_fulltext_check` 和 `retrieval_limits`，服务完成也不等于每条引用已经核验。
