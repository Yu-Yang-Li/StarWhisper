# 审稿回复模板 Response to Reviewers（R → A → C 格式）

> 逐条回应，先感谢再回应。每条用 R(Reviewer 意见) → A(作者回应) → C(正文改动位置)。
> 分歧处礼貌但据理，给证据；已改处必须指到具体章节/行，禁"已全部修改"式敷衍。
