# 投稿 Cover Letter 模板

> 简洁、具体、对准目标期刊读者。避免复述摘要全文；突出契合度、新意与重要性。

[日期]

Dear Dr. [主编姓名] / Editor-in-Chief, [期刊名],

我们谨提交题为 **"[论文标题]"** 的稿件，申请在 *[期刊名]* 发表（文章类型：[Article/Letter/…]）。

- **本文做了什么 + 核心发现**（1–2 句）：
- **为何契合本刊读者与范围**（1 句，对准期刊 scope）：
- **新意与重要性**（1–2 句，相对已有工作的推进）：
- **合规声明**：本研究为原创、未一稿多投；所有作者已审阅并同意投稿；[如涉及]伦理审批号 [xxx]；数据/代码可得性 [说明]。
- **利益冲突**：[无 / 说明]。
- **建议/回避审稿人**（如期刊允许）：[可选]

感谢您的考虑，期待您的回复。

此致
[通讯作者姓名]，代表全体作者
[单位、邮箱]
