# StarWhisper LC

Kepler / K2 光变分类的测试代码，对应论文 [StarWhisper LC](https://spj.science.org/doi/10.34133/icomputing.0110)（*Intelligent Computing*, 2025）。

| 目录 | 内容 |
| --- | --- |
| `Code/` | 测试代码 |
| `Result/` | 论文相关测试结果 |

这里不是完整训练复现包，也不包含 Telescope 观测 agent。模型结构见图：

https://yu-yang-li.github.io/StarWhisper/assets/starwhisper-lc.png

脉冲星候选分类是另一篇报告，代码在 [ACMISLab/StarWhisper-Pulsar](https://github.com/ACMISLab/StarWhisper-Pulsar)。
